01 · START HERE

Choose the shortest path into your work.

CommonNote can be a quiet personal notebook or a connected team workspace. You do not need to configure every layer before writing.

Open app→Create a note→Add structure when it helps
SOLO

Start with the note.

Create notebooks for broad areas, pin what is current, and turn only actionable lines into checklists or dated tasks.

PROJECT

Add a project lens.

Place existing notebooks in a project to read them as a hierarchy or relationship map. No duplicate copies are made.

TEAM

Share the source.

Invite an editor or viewer, then use comments, handoffs, messages, and reviews while the original note remains the anchor.

Five-minute setup

  1. Create one notebook for an active area such as Website launch, Semester, or Client work.
  2. Create a note and write the outcome, evidence, decisions, and next actions.
  3. Use a checklist for actions. Add @tomorrow or choose a due date when timing matters.
  4. Open To-dos to confirm the task appears with its Source Thread.
  5. Only then create a project, share the note, or add properties if the work needs them.

04 · LIVE COLLABORATION

Work in the same note without hiding authorship.

Presence shows who is connected; live cursors show where they are working; block authors preserve who contributed the text.

Note header→Share→Username→Editor or viewer
  1. The note owner opens Share, enters a username, and chooses editor or view-only access.
  2. When both people open the note, participant avatars and connection state appear in the header.
  3. Live selections and cursors use participant colors. Changes sync without a manual save.
  4. Turn on Authors to see the author attached to each block.
  5. Select a passage and use Comments when the discussion belongs to exact text.
  6. Use version history before restoring or comparing a substantial change.

Editor

Can change content, comments, checklists, files, and shared structure.

Viewer

Can read without changing the note. Access remains account-based.

Connection state

A participant dot confirms the shared session. Reconnect before assuming an edit was lost.

Versions

Automatic checkpoints and manual versions can be compared and restored.

05 · HANDOFF AND REVIEW

Send work as an actionable brief.

A handoff carries the task, recipient, deadline, instructions, and a route to the source. It is not just a forwarded sentence.

To-dos→Task card→Paper plane
  1. Open list or card view and choose the task’s paper-plane action.
  2. Select one or more recipients. Their open-work count helps you avoid blind assignment.
  3. Choose today, tomorrow, Friday, next week, or a custom due date.
  4. Write the outcome, constraints, and where feedback should be left in the handoff memo.
  5. Send. CommonNote creates a high-priority notification and a direct-message record with an Open task route.
  6. Use Handoffs to follow who sent, accepted, or passed the work onward.

Review instead of handoff

Use a review request when ownership is not changing and you need a decision on completed work. The reviewer can complete the review or request changes; the source task keeps the review state.

A memo should answer three things: what “done” means, when it is needed, and which source contains the background. The Source Thread handles the last part; write the first two plainly.
06 · MESSAGES AND FILES

Talk and transfer files beside the work.

Messages are for coordination; note attachments are for durable storage. The visible + button in the composer opens the file courier.

Top message icon→Person or team→Message or + file
  1. Open Messages and choose a person or team already connected through your workspace.
  2. Press Enter to send; use Shift+Enter for a new line.
  3. Press + or Send a file now, then choose a file. One file can be up to 200 MB.
  4. Keep the panel open long enough to confirm upload progress reaches delivery.
  5. The receiver downloads from the message bubble. Filename, size, and delivery time remain in the conversation.
  6. Transferred file bytes are deleted automatically after 24 hours.
File courier is temporary. Put material that must remain available in a note attachment or Figure frame. Use messenger files for fast delivery, not as the archive.

08 · PROJECTS AND RELATIONSHIP MAP

Read structure and reasoning in two different ways.

The hierarchy answers “where does this belong?” The relationship map answers “why are these things connected?” Both use the same project scope.

Project tree→Hierarchy or Map

Build the hierarchy

  1. Create nested notebooks, then choose New project and place the relevant top-level notebook in it.
  2. Expand project → notebook → note → task to see ownership, status, due date, and completion.
  3. Use All, late, today, next seven days, or mine to filter the full tree.
  4. Open the source from a title; use the … menu for placement, actions, and handoff.

Build the relationship map

  1. Switch to Map. Add notes from the same project or create private memo cards.
  2. Drag cards to arrange them and use the corner handle to resize a memo.
  3. Select a source node, choose connect, and select the target node.
  4. Give the link a label, then set solid, dashed, or dotted line; arrow direction; width; and color.
  5. Use zoom buttons or enter an exact percentage. Fit width, choose frame size, or type an exact frame height.
Evidence Thread: automatic [[note]] links appear as dashed relationships. Links you draw to record a decision are explicit and can be styled independently.
09 · TASKS, SCHEDULE TABLE, AND CALENDAR

Choose the view that answers today’s question.

All views use the same underlying tasks. Change the view instead of copying the task into another planning system.

List

Fast scanning and compact editing across many tasks.

Cards

One actionable card with status, owner, due signal, and Source Thread.

Board

Move work across personal or workspace status columns.

Action compass

Jump directly to overdue, today, next seven days, or undated work.

Schedule table

  1. Open Calendar and select Table.
  2. Choose a primary hierarchy: task, date, status, or note.
  3. Add multiple groups such as month → person. Use Reorder to change group priority.
  4. Filter by status, person, and date, then choose a sort.
  5. Drag the handle before a column header to reorder it; drag the divider to resize it.
  6. Open Property to add select, number, date, person, relation, formula, or rollup columns.
  7. Use each header menu for visibility, calculation, and property-specific controls.

Calendar

  1. Select Calendar for the month view.
  2. Click an empty date for quick add or drag across dates to create a range.
  3. Click an item to edit content, color, completion, date, or deletion.
  4. Use D-Day chips, today and week progress, overdue, and acknowledgment signals to set priority.
  5. In task text, natural language such as @tomorrow 3pm, @next Fri, or @Mon~Fri creates dates.

11 · RECORDS AND BACKUP

Keep a trustworthy history—and a readable exit.

Version history helps with editing mistakes. Finalization and acknowledgment help when a particular state of the note must be attested.

Version history

Compare automatic checkpoints and manual versions, then restore the state you need.

Finalize

Freeze a snapshot and attach author, time, and a content hash.

Acknowledge

Record that another person reviewed the finalized state.

Lock

Password-protect a private note or notebook and set its inactivity timeout.

Backup routine

  1. Use MD, HTML, or PDF in the note header for a readable note-level copy.
  2. Use the top backup action for a complete workspace ZIP with attachments.
  3. Keep one copy in a separate storage location and test opening it.
  4. Before restoring or importing over existing work, download a fresh backup first.
12 · TROUBLESHOOTING

Check state before assuming data is gone.

Most confusing situations come from scope, filters, connection state, or a view setting. Use this order before changing data.

SymptomCheck
Another person’s edits do not appearConfirm both people opened the same note, participant connection is active, and the network is online.
A task is missingCheck My vs All, status/person/date filters, completed state, project scope, and Action compass selection.
Project map is emptyCreate a project, place a notebook in its scope, select the correct project lens, then add notes to the map.
Imported images are missingConfirm the export ZIP included the image files and relative paths were preserved.
File transfer failsConfirm the receiver is a connected collaborator, the file is under 200 MB, and storage is available.
Text or controls are clippedReset app display zoom, then adjust editor text and line spacing inside View options.
A column will not moveDrag the handle before the header, not the label or resize divider. Keyboard users can focus the handle and use arrows.
