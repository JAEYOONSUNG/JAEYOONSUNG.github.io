01 · GETTING STARTED

시작하기

로그인한 뒤 처음 보이는 화면과 가장 빠른 기록 경로입니다.

앱 열기→로그인→왼쪽 사이드바
  1. commonnote.app에서 로그인합니다. 처음 쓰는 계정은 가입과 이메일 확인을 먼저 마칩니다.
  2. 왼쪽 사이드바에서 All Notes, 할 일, 프로젝트 트리, 캘린더 중 지금 할 일을 선택합니다.
  3. 빠른 기록은 오늘의 새 노트를 누릅니다. 오늘 날짜 제목과 체크리스트를 가진 노트가 열립니다.
  4. 상단의 보기 설정에서 줄간격, 여백, 글꼴을 내 화면에 맞춥니다.
기능이 보이지 않으면 먼저 브라우저 새로고침 후 왼쪽 사이드바가 접혀 있지 않은지 확인하세요. 사이드바 단축키는 ⇧⌘\입니다.
02 · NOTES

노트 만들기와 구조 잡기

빈 노트, 연구 템플릿, 노트북과 태그를 이용해 기록의 기본 구조를 만듭니다.

All Notes→새 노트 +→빈 노트 또는 템플릿
  1. 새 노트를 누르고 빈 노트 또는 실험 노트·논문 리뷰·회의록·프로젝트 킥오프 템플릿을 선택합니다.
  2. 첫 번째 제목 1 블록이 노트 제목이 됩니다. 제목을 바꾸면 목록과 탭 이름도 함께 바뀝니다.
  3. 노트 상단의 노트북 선택에서 저장할 노트북을 고르고, + tag에서 태그를 붙입니다.
  4. 편집기 도구에서 표, 체크리스트, 파일 첨부 또는 Figure 프레임을 삽입합니다.
  5. 자주 쓰는 구조는 템플릿으로 지정해 다음 노트에서 다시 사용합니다.

노트북

사이드바의 +로 만들고 부모 노트북을 지정해 여러 단계로 중첩할 수 있습니다.

태그

프로젝트와 무관한 주제·시약·상태를 가로질러 찾을 때 사용합니다.

파일과 Figure

파일은 커서 위치에 들어가며 Figure 프레임에서는 캡션과 배치를 함께 관리합니다.

목차

상단 목차 버튼을 열면 제목 블록 기준으로 긴 노트를 빠르게 이동합니다.

03 · FORMATTING

서식·색상·아이콘

기본 문서 형식부터 연구용 표기까지 선택 영역이나 현재 블록에 적용합니다.

노트 열기→편집기 상단 도구막대
범주지원 기능사용 방법
블록제목 1–3, 글머리, 번호, 체크리스트, 인용, 구분선, 접기 블록커서를 블록에 놓고 해당 도구를 누릅니다.
글자굵게, 기울임, 밑줄, 취소선, 아래·위 첨자, 인라인 코드, 링크글자를 선택한 뒤 적용합니다.
색형광펜 9색, 글자색 9색, 원하는 색 직접 선택선택 영역에 적용하며 제거 버튼으로 원래 색으로 돌립니다.
아이콘Lucide, Phosphor, Tabler, 이모지아이콘 검색에서 선택하면 주변 글자의 크기와 색을 따릅니다.
구조표, 코드 블록, TeX 수식, Figure 프레임삽입 후 블록별 편집 도구를 사용합니다.
형식Markdown 기반 편집, MD·HTML·PDF 출력편집기 오른쪽의 MD/HTML/PDF 버튼을 사용합니다.
CommonNote는 Markdown을 가져오고 내보낼 수 있지만 편집 화면에서는 표, 파일, 댓글, 작성자처럼 Markdown만으로 표현하기 어려운 정보도 함께 관리합니다.
04 · REAL-TIME COLLABORATION

실시간 공동 편집

같은 노트를 여러 사람이 동시에 열고, 누가 어디를 편집하는지와 누가 쓴 블록인지 구분합니다.

노트 상단→공유→아이디 입력→편집자/보기 전용
  1. 노트 소유자가 공유를 누르고 상대 아이디와 권한을 선택합니다.
  2. 상대가 노트를 열면 상단 참가자 아바타와 접속 점이 표시됩니다.
  3. 동시에 입력하면 각 사용자의 커서와 선택 영역이 사용자 색으로 보입니다.
  4. 작성자 표시를 켜면 블록마다 작성한 사람을 확인할 수 있습니다.
  5. 검토할 구간은 선택 후 댓글을 눌러 대화를 남깁니다.

편집자

노트 내용을 수정하고 댓글·체크리스트·파일을 함께 편집합니다.

보기 전용

내용은 읽되 수정할 수 없습니다. 공개 링크와 달리 계정 기반 접근입니다.

버전 기록

10분 간격 자동 저장과 수동 버전을 비교하고 복구합니다.

기록 확정·확인

현재 내용을 굳혀 작성자 또는 확인자의 서명과 해시를 남깁니다.

05 · HANDOFF & REVIEW

업무 전달과 검토 요청

체크리스트 업무를 담당자, 기한, 전달 메모와 함께 넘기고 메시지에서 원본으로 돌아옵니다.

할 일→카드/목록→전달
  1. 전달할 업무 카드에서 종이비행기 버튼 또는 전달을 누릅니다.
  2. 받는 사람을 한 명 이상 선택합니다.
  3. 오늘·내일·이번 주 금요일·다음 주 또는 직접 날짜로 기한을 지정합니다.
  4. 상대가 바로 이해할 수 있도록 배경과 요청사항을 전달 메모에 적습니다.
  5. 전달하면 수신자 메시지에 메모와 업무 열기 링크가 생기고 고우선순위 알림이 갑니다.

위임 흐름

보낸 사람 → 받은 사람 → 다시 전달된 경로와 현재 담당자를 확인합니다.

요청사항

상대가 보낸 업무 요청을 수락하거나 현재 노트와 연결합니다.

검토 상태

상태를 검토로 바꾸고 검토 요청을 보내면 변경 요청·완료를 추적합니다.

원본 유지

전달 뒤에도 Source Thread와 원본 노트 링크는 사라지지 않습니다.

06 · MESSENGER & FILES

메신저와 파일 전달

노트나 팀으로 함께 일하는 사람과 대화하고 큰 원자료를 짧게 전달합니다.

상단 말풍선→연락처 선택→메시지 또는 + 파일
  1. 상단 메시지 버튼을 열고 개인 또는 팀 대화를 선택합니다.
  2. 텍스트는 Enter로 보내고 Shift+Enter로 줄을 바꿉니다.
  3. + 파일에서 파일을 고르거나 바로 보내기 버튼을 사용합니다.
  4. 파일 하나는 최대 200MB이며 업로드 진행률이 표시됩니다.
  5. 파일 바이트는 24시간 뒤 자동 삭제되고, 파일명·크기·전달 시각은 대화에 남습니다.
메신저 파일은 영구 보관용이 아닙니다. 보존할 원자료는 노트의 파일 첨부 또는 Figure 프레임에 넣고, 메신저는 빠른 인수인계에 사용하세요.
07 · MIGRATION

데이터 가져오기와 이동

기존 앱의 내보내기 파일을 그대로 가져와 노트와 노트북 구조를 재구성합니다.

All Notes→가져오기→파일 선택 또는 끌어 놓기
출처준비할 파일옮겨지는 내용
NotionMarkdown & CSV 내보내기 ZIP페이지, 폴더, 이미지와 첨부 파일
ObsidianVault 폴더를 압축한 ZIPMarkdown, 폴더 계층, Wiki 링크, 첨부
Evernote.enex노트 본문, 제목, 생성 시각과 첨부
Markdown.md 또는 Markdown ZIP제목·목록·체크·표·코드·이미지
  1. 가져오기 전에 원본 앱에서 전체 내보내기를 한 번 더 보관합니다.
  2. 파일을 올리고 가져오기 요약에서 성공·건너뜀·오류 수를 확인합니다.
  3. 노트북 구조, 이미지, 내부 링크와 체크리스트를 표본 노트에서 검수합니다.
  4. 이동 뒤 전체 ZIP 백업을 받아 복구 가능한 사본을 만듭니다.
08 · PROJECTS & MAP

프로젝트 트리와 관계 맵

같은 범위를 계층과 네트워크 두 방식으로 읽습니다. 계층은 구조, 관계 맵은 판단 이유를 보여줍니다.

프로젝트 트리→계층 또는 관계 맵
  1. 사이드바 +에서 노트북을 만들고 부모 노트북을 지정해 연구 계층을 구성합니다.
  2. 새 프로젝트를 만들고 포함할 최상위 노트북을 프로젝트에 배치합니다.
  3. 계층 보기에서 프로젝트 → 노트북 → 노트 → 할 일을 접고 펼칩니다.
  4. 관계 맵에서 노트와 개인 메모를 캔버스에 놓고 두 노드를 선택해 연결합니다.
  5. 연결 라벨, 실선·점선·점, 화살표 방향, 굵기와 색을 설정합니다.
  6. 캔버스 배율, 폭 맞춤, 노드 크기와 프레임 높이를 작업량에 맞춥니다.
Source Thread: Wiki 링크로 생긴 자동 관계는 점선, 직접 만든 판단 관계는 실선으로 구분됩니다. 업무 카드의 원본 버튼에서도 같은 노트로 돌아갑니다.
09 · TASKS & CALENDAR

할 일, 일정 표와 캘린더

노트의 체크리스트와 빠른 입력 업무를 상태·담당자·기한·속성으로 관리합니다.

할 일 만들기

노트 체크리스트, 오늘의 새 노트 또는 할 일 상단 입력창에서 만듭니다.

보기 전환

목록·카드·보드, 사람별, 완료 기록, 위임 흐름과 요청사항으로 전환합니다.

자연어 날짜

@내일 3시, @다음주 금, @월~금, @7월 30일을 내용에 적습니다.

반복 업무

반복 업무에서 요일과 담당자를 정하면 해당 주기에 새 업무가 생성됩니다.

일정 표 사용 순서

  1. 캘린더 상단에서 표를 선택합니다.
  2. 업무별·날짜별·상태별·노트별 중 기본 계층을 고릅니다.
  3. 그룹을 여러 단계로 추가하고 순서를 드래그해 바꿉니다.
  4. 상태·사람·날짜 필터와 정렬을 적용합니다.
  5. 열 손잡이로 열 순서를 바꾸고 구분선을 드래그해 너비를 조절합니다.
  6. 속성에서 선택·숫자·날짜·사람·관계·수식·롤업 열을 추가합니다.

캘린더 사용 순서

  1. 빈 날짜를 눌러 바로 추가하거나 가로로 드래그해 기간 막대를 만듭니다.
  2. 항목을 눌러 내용, 색, 완료, 기한과 삭제를 수정합니다.
  3. 상단의 오늘·이번 주 진행률, 마감 지남, 확인 요청과 D-Day 칩으로 우선순위를 봅니다.
10 · RESEARCH TOOLS

수식, 시약 계산과 자동 계산

편집기와 일정 표에서 반복 계산을 줄입니다.

노트 상단 플라스크→시약 계산기
  1. 화학식(C6H12O6)을 입력하면 원자량을 합산해 분자량을 계산합니다.
  2. 시약 이름을 입력하면 PubChem에서 찾아오며, 한 번 찾은 결과는 다음 검색에 재사용됩니다.
  3. 목표 몰농도와 부피를 넣어 필요한 질량을 계산합니다.
  4. 원액 농도와 목표 농도를 넣어 덜어 쓸 부피를 계산합니다.
  5. 질량을 넣어 실제 몰수를 계산합니다.

TeX 수식

편집기 Σ 도구에서 LaTeX를 입력해 블록 수식을 삽입합니다.

수식 속성

일정 표 속성에서 숫자·날짜·선택 값을 조합한 계산식을 만듭니다.

롤업

관계 속성으로 연결된 항목의 개수·합계·완료율을 집계합니다.

진행률

그룹과 사람별 완료 수를 바탕으로 일정 표와 캘린더에서 자동 표시합니다.

11 · RECORDS & BACKUP

버전, 잠금과 백업

변경 이력과 소유권을 남기고 서비스 밖에서도 읽을 수 있는 사본을 만듭니다.

버전 히스토리

10분 간격 자동 버전과 수동 저장을 비교·복구합니다.

기록 확정·확인

내용 해시와 서명 시각, 작성자·확인자 관계를 남깁니다.

비밀번호 잠금

개인 노트나 노트북을 잠그고 비활성 시간 뒤 자동으로 다시 잠급니다.

내보내기

현재 노트는 MD·HTML·PDF, 전체 작업 공간은 첨부를 포함한 ZIP으로 받습니다.

  1. 노트별 사본은 편집기 오른쪽 MD, HTML, PDF 버튼을 사용합니다.
  2. 전체 사본은 상단 데이터베이스/백업 아이콘에서 형식과 저장 위치를 선택합니다.
  3. 백업 ZIP을 다른 저장소에 한 부 더 복사하고 정기적으로 열어 봅니다.
  4. 복구 전에는 기존 작업 공간을 먼저 백업해 덮어쓰기 위험을 줄입니다.
12 · TROUBLESHOOTING

문제 해결과 단축키
