노트와 공동 편집

기본 노트부터 연구 기록까지,
필요한 표현을 줄이지 않습니다.

문서 편집기의 기본기 위에 작성자, 버전, 시약 계산, 파일과 Figure를 연구 흐름에 맞게 더했습니다.

FORMAT

문서 기본기를 빠짐없이.

제목 1–3, 글머리·번호·체크리스트, 인용, 표, 링크, 접기 블록, 인라인 코드와 코드 블록을 지원합니다.

프로젝트에서 일정까지

같은 연구를
필요한 화면으로 바꿔 봅니다.

하나의 노트와 할 일이 프로젝트 계층, 관계 맵, 업무 카드, 일정 표와 캘린더에서 같은 원본을 가리킵니다.

전달과 대화

업무와 파일이
대화에서 끊기지 않게.

메시지는 별도 섬이 아니라 노트, 업무, 담당자와 연결된 전달 경로입니다.

MESSENGER + FILE COURIER

메시지와 원자료를 바로 보냅니다.

공동 작업자와 1:1로 대화하고 파일 하나당 최대 200MB를 전달합니다. 파일은 24시간 뒤 자동 정리되고 대화에는 전달 기록이 남습니다.

메신저·파일 설명 →
HANDOFF

업무를 맥락과 함께 넘깁니다.

받는 사람, 기한, 전달 메모를 지정하면 상대 메시지에 업무 열기 링크와 고우선순위 알림이 함께 도착합니다.

업무 전달 설명 →
REVIEW

검토 요청과 확인을 추적합니다.

업무를 검토 상태로 보내고 요청사항, 변경 요청, 완료 기록과 위임 흐름을 한 화면에서 따라갑니다.

연구 도구

계산과 표현을 위해
다른 창을 오가지 않게.

노트 안에서 필요한 계산과 시각 표시를 끝내고 그 결과를 그대로 기록합니다.

REAGENT CALCULATOR

화학식에서 분자량을 바로 계산.

화학식·시약 이름 검색, 분자량, 목표 몰농도와 부피, 원액 희석량, 질량에서 몰수를 계산합니다.

ICONS + COLOR

아이콘·이모지·컬러로 빠르게 표시.

세 아이콘 라이브러리, 이모지, 형광펜, 글자색과 직접 색상 선택을 지원하며 아이콘은 주변 글자의 크기와 색을 따릅니다.
