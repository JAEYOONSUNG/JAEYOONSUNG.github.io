01 · 시작하기

지금 하는 일로 들어가는 가장 짧은 길.

CommonNote는 조용한 개인 노트이면서 연결된 팀 작업 공간입니다. 쓰기 전에 모든 기능을 설정할 필요는 없습니다.

앱 열기→노트 만들기→필요할 때 구조 더하기
개인

노트부터 시작하세요.

큰 영역만 노트북으로 만들고, 현재 자료를 고정하며, 행동할 문장만 체크리스트나 날짜 업무로 바꿉니다.

프로젝트

프로젝트 렌즈를 더하세요.

기존 노트북을 프로젝트에 배치하면 복제 없이 계층 또는 관계 맵으로 읽을 수 있습니다.

팀

원본을 공유하세요.

편집자나 보기 전용 사용자를 초대하고 원본 노트를 중심으로 댓글, 전달, 메시지와 검토를 이어갑니다.

5분 설정

  1. 웹사이트 출시, 이번 학기, 고객 업무처럼 현재 영역의 노트북 하나를 만듭니다.
  2. 노트를 만들고 목표, 근거, 결정과 다음 행동을 씁니다.
  3. 행동은 체크리스트로 바꾸고, 시점이 중요하면 @내일 또는 기한을 지정합니다.
  4. 할 일에서 업무와 Source Thread가 함께 보이는지 확인합니다.
  5. 그다음 필요할 때 프로젝트, 공유 또는 사용자 속성을 더합니다.
02 · 노트와 파일

원자료를 쓰고, 찾고, 연결합니다.

노트가 오래 남는 원본입니다. 업무, 프로젝트 노드, 메시지와 일정은 분리된 복사본이 아니라 이곳으로 돌아와야 합니다.

All Notes→새 노트→노트북 · 태그 · 본문
목적기능알아둘 점
정리다단계 노트북끌거나 부모를 지정합니다. 노트를 옮겨도 업무의 Source Thread는 유지됩니다.
찾기검색, 태그, 즐겨찾기, 최근검색은 제목과 본문을 모두 찾고, 태그는 노트북 경계를 넘습니다.
재사용템플릿노트를 템플릿으로 표시하고 반복 업무마다 새 복사본을 만듭니다.
연결[[노트]] 링크대괄호 두 개로 다른 노트를 연결하면 관계 맵의 점선 근거가 됩니다.
첨부파일 또는 Figure 프레임참고 자료는 파일, 배치·캡션·크기가 중요한 이미지는 Figure 프레임을 사용합니다.
보호노트·노트북 잠금민감한 개인 자료에 비밀번호와 비활성 자동 잠금 시간을 설정합니다.
Source Thread는 파생된 업무가 생성 노트와 노트북으로 돌아가는 길을 유지한다는 뜻입니다. 업무 카드의 원본 버튼이나 일정 표의 노트 제목을 사용하세요.
03 · 서식

도구를 바꾸지 않고 필요한 만큼 표현합니다.

인라인 서식은 글자를 선택하고, 제목·목록·인용·코드·표·수식·접기 블록은 해당 블록에 커서를 둔 뒤 적용합니다.

노트 열기→편집기 도구막대
범주지원 기능쓰임
블록제목 1–3, 글머리, 번호, 체크리스트, 인용, 구분선, 접기긴 노트를 훑기 쉽게 만들고 결정을 행동으로 바꿉니다.
글자굵게, 기울임, 밑줄, 취소선, 위·아래 첨자, 인라인 코드, 링크새 구조를 만들지 않고 의미를 강조합니다.
표시글꼴, 크기, 형광펜, 글자색, 직접 색상, 이모지, Lucide·Phosphor·Tabler우선순위, 상태와 의미를 위한 개인 마킹 체계를 만듭니다.
구조화 내용표, 코드 블록, TeX 수식, Figure 프레임, 파일데이터, 예시, 수식과 시각 근거를 설명 옆에 둡니다.
이동 형식Markdown 가져오기, MD·HTML·PDF 내보내기텍스트를 가져오고 앱 밖에서도 읽을 사본을 만듭니다.
앱 전체의 화면 배율과 편집기 글자 크기는 다릅니다. 화면 배율은 인터페이스 전체, 보기 설정의 글자·줄간격·표 글자·문서 폭은 콘텐츠 프레임 안을 조절합니다.
04 · 실시간 협업

같이 쓰되, 누가 썼는지는 지우지 않습니다.

접속 상태는 누가 들어와 있는지, 실시간 커서는 어디를 편집하는지, 블록 작성자는 누가 기여했는지 남깁니다.

노트 상단→공유→아이디→편집자/보기 전용
  1. 소유자가 공유를 열고 사용자 아이디와 편집자 또는 보기 전용 권한을 고릅니다.
  2. 두 사람이 같은 노트를 열면 상단에 참가자 아바타와 연결 상태가 표시됩니다.
  3. 실시간 커서와 선택 영역은 사용자 색으로 보이며 별도 저장 없이 동기화됩니다.
  4. 작성자를 켜면 블록마다 기여한 사람을 확인할 수 있습니다.
  5. 정확한 문장을 두고 대화하려면 선택 후 댓글을 사용합니다.
  6. 큰 변경을 되돌리거나 비교하기 전에는 버전 히스토리를 확인합니다.

편집자

본문, 댓글, 체크리스트, 파일과 공유 구조를 수정합니다.

보기 전용

계정 기반으로 읽되 노트를 변경하지 못합니다.

연결 상태

참가자 점으로 같은 공동 편집 세션인지 확인합니다.

버전

자동 체크포인트와 수동 버전을 비교하고 복구합니다.

05 · 업무 전달과 검토

실행 가능한 브리프로 일을 보냅니다.

업무 전달에는 할 일, 받는 사람, 기한, 지시와 원본으로 돌아가는 길이 함께 갑니다. 문장 하나를 전달하는 것과 다릅니다.

할 일→업무 카드→종이비행기
  1. 목록 또는 카드 보기에서 업무의 종이비행기 버튼을 누릅니다.
  2. 한 명 이상의 받는 사람을 고릅니다. 표시된 미완료 업무 수로 무리한 배정을 피할 수 있습니다.
  3. 오늘, 내일, 이번 주 금요일, 다음 주 또는 직접 날짜를 선택합니다.
  4. 완료 기준, 제약과 피드백을 남길 곳을 전달 메모에 씁니다.
  5. 보내면 고우선순위 알림과 업무 열기 경로가 있는 개인 메시지 기록이 생깁니다.
  6. 전달 보기에서 누가 보내고, 수락하고, 다시 전달했는지 확인합니다.

전달 대신 검토 요청

담당은 바꾸지 않고 끝난 결과에 판단이 필요하면 검토를 요청합니다. 검토자는 완료하거나 변경을 요청할 수 있고 원본 업무에 검토 상태가 남습니다.

좋은 전달 메모는 완료 기준, 필요한 시점, 배경 자료의 위치에 답합니다. 마지막은 Source Thread가 처리하므로 앞의 두 가지를 분명히 쓰세요.
06 · 메시지와 파일

업무 옆에서 대화하고 파일을 전달합니다.

메시지는 조율을 위한 곳, 노트 첨부는 오래 보존할 곳입니다. 입력창의 분명한 + 버튼이 파일 전달을 엽니다.

상단 메시지→사람 또는 팀→메시지 또는 + 파일
  1. 메시지를 열고 작업 공간에서 연결된 사람이나 팀을 선택합니다.
  2. Enter로 보내고 Shift+Enter로 줄을 바꿉니다.
  3. + 또는 지금 파일 보내기를 누릅니다. 파일 하나는 최대 200MB입니다.
  4. 업로드 진행률이 전달 완료에 도달하는지 확인합니다.
  5. 받는 사람은 메시지 버블에서 내려받고 파일명, 크기, 전달 시각은 대화에 남습니다.
  6. 전달 파일의 바이트는 24시간 뒤 자동 삭제됩니다.
파일 전달은 임시입니다. 계속 보관할 자료는 노트 첨부 또는 Figure 프레임에 넣고 메신저 파일은 빠른 전달에 사용하세요.
07 · 마이그레이션

기존 구조를 납작하게 만들지 않고 가져옵니다.

가능한 경우 원본 폴더에서 노트북 계층을 다시 만들고 지원되는 첨부 자료를 노트와 함께 옮깁니다.

All Notes→가져오기→파일 선택 또는 끌어 놓기
출처준비할 파일예상 결과
NotionMarkdown & CSV 내보내기 ZIP페이지, 폴더, 이미지와 첨부
ObsidianVault 폴더 ZIPMarkdown, 폴더 계층, Wiki 링크와 첨부
Evernote.enex노트 본문, 제목, 시각과 첨부
Markdown.md 또는 폴더 ZIP제목, 목록, 체크, 표, 코드와 이미지
  1. 가져오기 전 원본 내보내기를 손대지 않은 상태로 보관합니다.
  2. 파일을 올리고 성공, 건너뜀과 오류 수를 확인합니다.
  3. 중첩 폴더, 내부 링크, 이미지와 체크리스트가 있는 대표 노트를 검사합니다.
  4. 검수가 끝나면 전체 CommonNote 작업 공간 ZIP을 복구 기준점으로 받습니다.
08 · 프로젝트와 관계 맵

구조와 판단 근거를 서로 다른 방식으로 읽습니다.

계층은 “어디에 속하는가”, 관계 맵은 “왜 연결됐는가”에 답합니다. 두 화면은 같은 프로젝트 범위를 사용합니다.

프로젝트 트리→계층 또는 관계 맵

계층 만들기

  1. 다단계 노트북을 만든 뒤 새 프로젝트에서 관련 최상위 노트북을 배치합니다.
  2. 프로젝트 → 노트북 → 노트 → 업무를 펼쳐 담당, 상태, 기한과 완료율을 봅니다.
  3. 전체, 지연, 오늘, 7일 안, 내 업무로 전체 트리를 즉시 거릅니다.
  4. 제목으로 원본을 열고 … 메뉴로 배치, 작업과 전달을 실행합니다.

관계 맵 만들기

  1. 관계 맵으로 전환하고 같은 프로젝트 노트 또는 개인 메모 카드를 더합니다.
  2. 카드를 끌어 배치하고 모서리 손잡이로 메모 크기를 바꿉니다.
  3. 시작 노드에서 연결을 누른 뒤 목표 노드를 선택합니다.
  4. 연결 라벨, 실선·점선·점, 화살표 방향, 굵기와 색을 설정합니다.
  5. 버튼 또는 정확한 % 입력으로 배율을 바꾸고, 폭 맞춤·프레임 크기·정확한 높이를 설정합니다.
Evidence Thread: 자동 [[노트]] 링크는 점선입니다. 판단을 기록하기 위해 직접 그린 연결은 별도로 꾸밀 수 있습니다.
09 · 할 일, 일정 표와 캘린더

오늘의 질문에 맞는 보기로 바꿉니다.

모든 화면은 같은 업무 데이터를 사용합니다. 다른 일정 시스템에 복사하지 말고 보기를 바꾸세요.

목록

많은 업무를 빠르게 훑고 간결하게 수정합니다.

카드

상태, 담당, 기한 신호와 Source Thread를 한 장에서 봅니다.

보드

개인 또는 작업 공간 상태 열 사이로 업무를 옮깁니다.

작업 나침반

지연, 오늘, 7일 안 또는 기한 없음 업무로 즉시 이동합니다.

일정 표

  1. 캘린더를 열고 표를 선택합니다.
  2. 업무, 날짜, 상태 또는 노트 중 기본 계층을 고릅니다.
  3. 월 → 사람처럼 그룹을 여러 단계로 더하고 순서 버튼으로 우선순위를 바꿉니다.
  4. 상태, 사람과 날짜로 필터한 뒤 정렬 방식을 고릅니다.
  5. 열 제목 앞 손잡이를 끌어 순서를 바꾸고 구분선을 끌어 너비를 조절합니다.
  6. 속성에서 선택, 숫자, 날짜, 사람, 관계, 수식 또는 롤업 열을 추가합니다.
  7. 각 열 메뉴에서 표시, 계산과 타입별 세부 설정을 조절합니다.

캘린더

  1. 캘린더를 눌러 월간 보기로 전환합니다.
  2. 빈 날짜를 눌러 빠르게 추가하거나 날짜 구간을 끌어 기간을 만듭니다.
  3. 항목을 눌러 내용, 색, 완료, 날짜와 삭제를 수정합니다.
  4. D-Day, 오늘·이번 주 진행률, 지연과 확인 요청 신호로 우선순위를 정합니다.
  5. @내일 3시, @다음주 금, @월~금 같은 자연어로 기한을 만듭니다.
10 · 속성과 자동화

반복이 시작되는 곳에 구조를 더합니다.

속성은 반복되는 업무 메타데이터를 필터 가능한 타입 값으로 만들고 수식과 롤업은 그 구조 위에서 계산합니다.

속성용도예시
선택통제된 라벨채널, 우선순위, 단계
숫자비교 가능한 값예산, 노력, 점수
날짜추가 마일스톤검토일, 공개일

11 · 기록과 백업

신뢰할 수 있는 이력과 읽을 수 있는 출구를 만듭니다.

버전 히스토리는 편집 실수를 되돌리고, 기록 확정과 확인은 특정 시점의 내용에 누가 동의했는지 남깁니다.

버전 히스토리

자동 체크포인트와 수동 버전을 비교하고 필요한 상태를 복구합니다.

기록 확정

스냅샷을 고정하고 작성자, 시각과 내용 해시를 붙입니다.

확인

다른 사람이 확정 상태를 검토했음을 기록합니다.

잠금

개인 노트나 노트북을 비밀번호로 보호하고 비활성 시간을 정합니다.

백업 습관

  1. 노트 상단 MD, HTML 또는 PDF로 읽을 수 있는 노트 사본을 만듭니다.
  2. 상단 백업에서 첨부를 포함한 전체 작업 공간 ZIP을 받습니다.
  3. 다른 저장 위치에 한 부를 두고 실제로 열리는지 검사합니다.
  4. 기존 데이터 위에 복구하거나 가져오기 전에는 최신 백업을 먼저 받습니다.
12 · 문제 해결

데이터가 사라졌다고 판단하기 전에 상태부터 확인하세요.

헷갈리는 상황 대부분은 범위, 필터, 연결 또는 보기 설정에서 옵니다. 데이터를 바꾸기 전에 아래 순서를 확인합니다.

증상확인할 것
다른 사람 입력이 보이지 않음같은 노트를 열었는지, 참가자 연결이 켜졌는지, 네트워크가 온라인인지 확인합니다.
업무가 보이지 않음내 할 일/전체, 상태·사람·날짜 필터, 완료 여부, 프로젝트 범위와 나침반 선택을 봅니다.
관계 맵이 비어 있음프로젝트를 만들고 노트북을 배치했는지, 맞는 프로젝트 렌즈인지, 노트를 맵에 추가했는지 봅니다.
가져온 이미지가 없음원본 ZIP에 이미지가 포함됐는지, 상대 경로가 유지됐는지 확인합니다.
파일 전달 실패받는 사람이 연결된 공동 작업자인지, 200MB 이하인지, 저장 공간이 있는지 봅니다.
글자나 버튼이 잘림앱 화면 배율을 재설정하고 보기 설정의 글자 크기·줄간격을 조절합니다.
열 순서가 바뀌지 않음제목이나 너비 구분선이 아니라 열 제목 앞 이동 손잡이를 끕니다. 키보드는 손잡이에 초점을 두고 방향키를 씁니다.
