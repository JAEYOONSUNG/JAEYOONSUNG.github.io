이어가는 게 어렵습니다.

좋은 노트는 작성이 끝난 뒤 조용해지면 안 됩니다. CommonNote는 일이 다른 모습으로 바뀌어도 이유, 다음 행동, 담당자와 날짜를 원본에 붙여 둡니다.

  1. 기록세부 내용
  2. 결정중요한 것
  3. 담당다음 행동
  4. 일정약속한 시점
  5. 보존원본 맥락

서로 다른 일, 하나의 작업 공간

직함이 아니라, 일이 이어지는 방식에 맞췄습니다.

개인

매일의 기록, 계획, 참고 자료와 알림이 서로 끊기지 않습니다.

학습

수업 노트, 출처, 복습 과제와 마감일을 탐색 가능한 구조로 정리합니다.

창작

아이디어, 초안, 피드백, 자료와 공개 준비를 최초 생각과 함께 이어갑니다.

프로젝트 팀

공유 노트, 담당, 검토, 인수인계와 납기를 원본에 붙여 관리합니다.

운영

반복 업무, 상태 체계, 구조화 속성, 파일과 책임 기록을 한곳에 둡니다.

연구

방법, Figure, 수식, 버전, 서명과 특화 계산이 필요할 때 깊게 사용합니다.

세부 내용을 쓰고, 원본을 지키세요.

얇은 입력칸이 아닌,
제대로 된 편집기.

일반 텍스트나 Markdown으로 시작하세요. 일이 요구할 때만 제목, 체크리스트, 표, 파일, Figure, 수식, 색상, 아이콘과 댓글을 더하면 됩니다.

  • 이동 가능한 구조.제목, 목록, 표, 코드, 링크, 접기 블록, Markdown 가져오기와 내보내기.
  • 번거롭지 않은 강조.글꼴, 글자 크기, 형광펜, 글자색, 이모지와 세 가지 검색형 아이콘 라이브러리.
  • 신뢰할 수 있는 기록.실시간 커서, 블록 작성자, 댓글, 버전, 기록 확정, 확인과 서명.

같은 노트와 할 일을 계층, 관계 맵, 업무 카드, 구조화 표 또는 캘린더로 보세요. 모든 화면은 일이 시작된 원본으로 돌아갑니다.

계층

아침 요약부터 노치까지.

오늘 할 일이
먼저 찾아옵니다.

캘린더를 열지 않아도 하루가 시작됩니다. 정한 시각에 오늘 일정이 푸시로 오고, 맥에서는 노치와 바탕화면 위젯이 진행률을 보여 줍니다. 날짜를 누르면 그날의 게시판이 기간 업무와 하루 업무로 나뉘어 펼쳐집니다.

  • 아침 일정 요약.근무일 아침, 원하는 시각에 오늘 일정·지난 마감·수락 대기를 한 번의 푸시로 받습니다.
  • 맥 노치와 바탕화면 위젯.노치 옆에 오늘 진행률이 늘 떠 있고, 마우스를 대면 목록이 펼쳐집니다. 바탕화면 달력 위젯은 날짜에 대면 그날 업무를 보여 줍니다.
  • 날짜 게시판.기간 업무와 하루 업무를 나눠 D-Day, 끝나는 날, 시각과 함께 카드로 봅니다. 카드를 누르면 원본 노트로 갑니다.
  • iPhone.다이내믹 아일랜드에 오늘 상황이 실시간으로 표시됩니다.

가져오고, 잇고, 맡기세요.

이미 있는 일정과 도구를
그대로 연결합니다.

애플 캘린더의 .ics 파일이나 iCloud 구독 링크를 넣으면 반복 일정까지 펼쳐 캘린더 노트에 심고, 같은 일정을 다시 넣어도 두 번 생기지 않습니다. 자주 쓰는 문구는 스니펫으로, 스크립트와 AI 에이전트는 마크다운 API로 노트를 읽고 씁니다.

  • 애플 캘린더 가져오기..ics 파일 또는 webcal 구독 링크. 매주·매달 반복과 예외 회차를 펼치고, 범위를 골라 미리 본 뒤 넣습니다.
  • 스니펫.계정에 저장되는 자주 쓰는 문구. 편집기에서 / 메뉴로 고르거나 ;단축어 뒤에 띄어쓰기를 치면 그 자리에 펼쳐집니다.
  • 마크다운 API.개인 토큰으로 노트 목록·본문 읽기, 새 노트, 끝에 덧붙이기. Claude Code 같은 에이전트가 연구노트를 바로 다룹니다.
curl -H "Authorization: Bearer cnk_…" \
     -H "Accept: text/markdown" \
     https://commonnote.app/api/v1/notes/<note-id>
